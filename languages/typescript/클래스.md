## TypeScript 클래스 — JS 클래스에 타입을 입히면 무엇이 달라지는가

같은 구조의 객체를 여러 개 만들 때 매번 프로퍼티를 반복 작성하는 건 비효율적이다. 자바스크립트의 클래스는 이 중복을 해결하고, TypeScript는 여기에 **필드 타입 선언**과 **접근 제어자**를 추가해서 더 안전한 코드를 작성할 수 있게 한다.

---

### 자바스크립트 클래스 — 중복 제거의 출발점

아래처럼 같은 구조의 객체를 반복 작성하면 중복이 발생한다.

```javascript
let studentA = {
  name: 'bysu',
  grade: 'a+',
  age: 27,
  study() {
    console.log('열심히 공부 함');
  },
};

let studentB = {
  name: 'dobby',
  grade: 'b+',
  age: 28,
  study() {
    console.log('열심히 공부 함');
  },
};
```

클래스를 사용하면 **틀(template)**을 한 번 정의하고 인스턴스를 찍어낼 수 있다.

```javascript
class Student {
  // 필드
  name;
  grade;
  age;

  // 생성자 — new Student(...)로 호출될 때 실행된다
  constructor(name, grade, age) {
    this.name = name;
    this.grade = grade;
    this.age = age;
  }

  // 메서드
  study() {
    console.log('study');
  }

  introduce() {
    console.log('hi');
  }
}
```

클래스 상속으로 기존 클래스를 확장할 수도 있다. `super()`는 부모 클래스의 생성자를 호출한다.

```javascript
class StudentDeveloper extends Student {
  favoriteSkill;

  constructor(name, grade, age, favoriteSkill) {
    super(name, grade, age); // 부모(Student)의 constructor 호출
    this.favoriteSkill = favoriteSkill;
  }
}
```

### TypeScript 클래스 — 필드에 타입을 선언한다

TypeScript에서는 클래스 필드에 타입을 명시해야 한다. 생성자 파라미터에도 타입을 붙인다.

```typescript
class Employee {
  name: string;
  age: number;
  position: string;

  constructor(name: string, age: number, position: string) {
    this.name = name;
    this.age = age;
    this.position = position;
  }

  work() {
    console.log('work');
  }
}
```

JS 클래스와 구조는 동일하지만, 필드와 파라미터에 타입이 붙어서 잘못된 값을 넣으면 컴파일 시점에 잡아낸다.

---

### 접근 제어자 (Access Modifier)

TypeScript는 클래스 멤버의 접근 범위를 제어하는 세 가지 키워드를 제공한다.

| 접근 제어자 | 클래스 내부 | 파생(자식) 클래스 | 외부 |
|---|---|---|---|
| `public` (기본값) | O | O | O |
| `protected` | O | O | X |
| `private` | O | X | X |

```typescript
class Employee {
  public name: string;      // 어디서든 접근 가능
  protected age: number;     // 자식 클래스까지만 접근 가능
  private position: string;  // 이 클래스 안에서만 접근 가능

  constructor(name: string, age: number, position: string) {
    this.name = name;
    this.age = age;
    this.position = position;
  }
}
```

---

### 생성자 축약 문법

생성자 파라미터에 접근 제어자를 붙이면, **필드 선언과 할당을 한 번에** 처리할 수 있다.

```typescript
// 축약 전 — 필드 선언, 파라미터, 할당을 각각 작성
class Employee {
  name: string;
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}

// 축약 후 — 접근 제어자를 붙이면 자동으로 필드 생성 + 할당
class Employee {
  constructor(
    public name: string,
    public age: number,
  ) {}
}
```

두 코드는 완전히 동일하게 동작한다. 필드가 많은 클래스에서 보일러플레이트를 크게 줄여준다.

---

### 정리

- **클래스**는 같은 구조의 객체를 반복 생성할 때 중복을 제거하는 틀이다
- TypeScript 클래스는 필드에 **타입 선언**을 강제해서 컴파일 타임에 오류를 잡는다
- **접근 제어자**(`public`, `protected`, `private`)로 멤버의 노출 범위를 제한한다
- 생성자 파라미터에 접근 제어자를 붙이면 **필드 선언과 할당을 자동화**할 수 있다
